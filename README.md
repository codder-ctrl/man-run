# Man Run

Fun Run tarzında, tarayıcıda oynanan hayvanlı bir koşu yarışı. Karakterin kendi koşar. Sen zıplarsın, "?" kutularından çıkan eşyalarla rakiplerini durdurursun ve bitiş bayrağına ilk varmaya çalışırsın.

- **Zıpla:** Ekranın sol tarafına dokun ya da `Boşluk` tuşuna bas. Basılı tutarsan daha yükseğe zıplarsın.
- **Eşya:** Sağ alttaki düğmeye dokun ya da `E` tuşuna bas.

**Çalıştırma:** `python -m http.server 8004` komutunu çalıştır, sonra http://localhost:8004 adresini aç.

**Testler:** `npm test`.
